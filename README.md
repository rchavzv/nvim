# Configuración de Neovim

⚠️ **Importante:** Esta configuración está diseñada para **Neovim v0.11 o superior**.  
Usar versiones anteriores puede causar errores con **Mason, LSP, Treesitter y plugins**.

## Instalación

1. Clona este repositorio en `~/.config/nvim`
2. Compila e instala Neovim v0.11+ (si aún no lo tienes)
3. Abre Neovim y deja que `lazy.nvim` instale los plugins

## Plugins principales

- Mason (gestor de LSP)
- nvim-lspconfig
- Treesitter
- lazy.nvim
- Otros plugins de productividad
